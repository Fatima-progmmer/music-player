# 🎵 Music Player  

A simple and interactive **Music Player** built using **HTML, CSS, and JavaScript**. This project allows users to play, pause, skip tracks, and enjoy a smooth music experience with a visually appealing UI.  

## 🌟 Features  
✅ Play/Pause music 🎶  
✅ Next/Previous track navigation ⏭️⏮️  
✅ Shuffle and Repeat modes 🔀🔁  
✅ Volume and progress control 🎚️  
✅ Dark/Light theme switch 🌙☀  

## 🛠️ Technologies Used  
- **HTML** – For structuring the player  
- **CSS** – For styling and UI design  
- **JavaScript** – For interactivity and functionality  

## 🚀 How to Use  
1. Clone the repository:  
   ```bash
   git clone https://github.com/Fatima-progmmer/music-player.git
   ```  
2. Open the `index.html` file in your browser.  
3. Enjoy your favorite music! 🎧
